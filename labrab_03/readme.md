Лабораторная работа 03. Парсинг данных (TIOBE index)
Программная инженерия, Node.js, 2026-2027

Задание: в 02-while.js разобрать HTML страницы TIOBE - в каждой строке таблицы
top20 найти все ячейки td и извлечь данные из столбцов 0, 1, 4, 5:
0 - место в рейтинге сейчас, 1 - место год назад, 4 - название языка, 5 - рейтинг.
Разбор только строковыми методами indexOf и slice, без сторонних библиотек.

Файлы:
02-while.js - код лабораторной работы;
data/tiobe-top20_fetch.html - сохранённая страница сайта, входные данные;
data/tiobe-top20_while.json - результат: 20 языков, объекты { pos, prev, lang, rate };
01-axios-get.js - скрипт, с помощью которого страница скачивается с сайта.

Запуск (в папке labrab_03, нужен только Node.js):
node 02-while.js

Программа выводит список из 20 языков и сохраняет его в файле
data/tiobe-top20_while.json.
